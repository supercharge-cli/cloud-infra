# Dashboard

After login, open **[Dashboard](/dashboard)**.

## Create an instance

1. Enter a workspace name.
2. Pick **INR** or **USD** (prices shown in the dashboard).
3. Click **Pay & create** and complete Razorpay checkout.
4. When payment succeeds, the instance appears in your list (paid for 30 days).

You only see **your** instances. Paused ones stay in the list so you can resume them.

## Configure AI + Telegram

Select an instance, then:

| Field | What to enter |
| --- | --- |
| Provider | OpenAI-compatible or Anthropic |
| Model / Base URL | Optional |
| API key | Your LLM key (leave blank to keep the current one) |
| Telegram bot token | From [@BotFather](https://t.me/BotFather) |
| Allow all users | Off = pairing (recommended); on = anyone can talk to the bot |

Use **Save config** or **Save & restart** so the agent reloads settings.

## Resume a paused instance

If status is **paused**, the machine is idle but still yours.

- Click **Resume sandbox** / **Wake / resume**.
- If payment expired, **Renew** first, then resume.

See [Pause & resume](/docs/pause-resume).

## Destroy

**Destroy** permanently deletes that sandbox. This cannot be undone. Billing access for that seat is not automatically refunded.
