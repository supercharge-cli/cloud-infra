# Getting started

**Vectra Cloud** gives you a private cloud sandbox for an AI coding agent, with a dashboard to manage keys, chat channels, billing, logs, and updates.

## What you get

| | |
| --- | --- |
| Machine | **4 vCPU · 8 GB RAM** |
| Agent | Coding agent preinstalled in the sandbox image |
| Chat | Telegram, Discord, and/or Slack (pairing or open access) |
| Idle | Auto-pauses to save cost — still yours; resume anytime |
| Ops | Dashboard shell, **View logs**, opt-in **CLI Update & restart** |
| Price | 1 free instance · extra per instance / 30 days (see dashboard) |

## First steps

1. [Sign up](/signup) with email and password.
2. Open the [dashboard](/dashboard).
3. Create your free instance (or pay for another).
4. Open the instance → paste your **AI API key** and at least one **channel token** (Telegram / Discord / Slack) → **Save & restart**.
5. Message the bot, copy the pairing code, and **Approve** it in the dashboard.
