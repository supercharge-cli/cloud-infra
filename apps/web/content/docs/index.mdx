# Getting started

**Vectra Cloud** gives you a private cloud sandbox for an AI coding agent (XibeCode), with a dashboard to manage keys, Telegram, and billing.

## What you get

| | |
| --- | --- |
| Machine | **4 vCPU · 8 GB RAM** |
| Agent | XibeCode preinstalled |
| Chat | Telegram (pairing or open access) |
| Idle | Auto-pauses to save cost — still yours; resume anytime |
| Price | Per instance / 30 days (see dashboard for current rates) |

## First steps

1. [Sign up](/signup) with email and password.
2. Open the [dashboard](/dashboard).
3. Choose **INR** or **USD**, name your workspace, and pay with Razorpay.
4. After payment, the sandbox is created automatically.
5. Open the instance → paste your **AI API key** and optional **Telegram bot token** → **Save & restart**.
6. Message the bot, copy the pairing code, and **Approve** it in the dashboard.
