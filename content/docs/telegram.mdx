# Telegram

Talk to your cloud agent from Telegram.

## Setup

1. Create a bot with [@BotFather](https://t.me/BotFather) and copy the token.
2. In the dashboard, open your instance → paste the token → **Save & restart**.
3. Open the bot in Telegram and send `/start` (or any message).

## Pairing (default)

By default only approved users can chat with the bot.

1. The bot replies with a **pairing code**.
2. Dashboard → that instance → **Telegram pairing**.
3. Paste the code → **Approve**.
4. You can chat normally.

Use **Refresh** if the code is not listed yet (agent may still be starting).

## Open access

If you enable **Allow all Telegram users** when saving config, anyone who finds the bot can message it. Prefer pairing for private use.

## After the sandbox pauses

If the bot goes quiet after idle time, open the dashboard and **Resume** the instance, then message again. See [Pause & resume](/docs/pause-resume).
